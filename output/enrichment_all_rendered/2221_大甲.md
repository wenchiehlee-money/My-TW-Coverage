# 2221 - 大甲

## 業務簡介
**板塊:** Basic Materials
**產業:** Steel
**市值:** 1,864 百萬台幣
**企業價值:** 1,797 百萬台幣

大甲永和機械 (2221) 為台灣領先之[[不鏽鋼]]焊接管件製造商。雙事業：潔淨級 (U [![HP Inc.](https://img.shields.io/badge/HP%20Inc.-blue)](HPQ_HP%20Inc..md)，佔約50%) 供應半導體/光電製程管路，為 [![台積電](https://img.shields.io/badge/%E5%8F%B0%E7%A9%8D%E9%9B%BB-blue)](2330_%E5%8F%B0%E7%A9%8D%E9%9B%BB.md) 合格供應商；化工級 (佔約50%) 主要外銷日本石化業。與日本[[MIE]]株式會社資本及業務合作。上游[[不鏽鋼]]管板來自[[華新麗華]]、[![燁聯](https://img.shields.io/badge/%E7%87%81%E8%81%AF-blue)](9957_%E7%87%81%E8%81%AF.md) 及日本進口。另供 [![聯電](https://img.shields.io/badge/%E8%81%AF%E9%9B%BB-blue)](2303_%E8%81%AF%E9%9B%BB.md)、[![力積電](https://img.shields.io/badge/%E5%8A%9B%E7%A9%8D%E9%9B%BB-blue)](6770_%E5%8A%9B%E7%A9%8D%E9%9B%BB.md)、[![友達](https://img.shields.io/badge/%E5%8F%8B%E9%81%94-blue)](2409_%E5%8F%8B%E9%81%94.md)、[![群創](https://img.shields.io/badge/%E7%BE%A4%E5%89%B5-blue)](3481_%E7%BE%A4%E5%89%B5.md)。
