# 1713 - 國化

## 業務簡介
**板塊:** Basic Materials
**產業:** Specialty Chemicals
**市值:** 7,004 百萬台幣
**企業價值:** 6,663 百萬台幣

國化實業 (1713，Cathay Chemical Works) 為台灣特用化學品製造商，產品涵蓋清洗劑、半導體濕製程化學品及工業化學品。近年成功切入半導體供應鏈，子公司[[和淞科技]]專注半導體特化品，供應 [![台積電](https://img.shields.io/badge/%E5%8F%B0%E7%A9%8D%E9%9B%BB-blue)](2330_%E5%8F%B0%E7%A9%8D%E9%9B%BB.md)、[![Micron](https://img.shields.io/badge/Micron-blue)](MU_Micron.md) 等晶圓廠。

## 供應鏈位置
**上游 (原料):**
- **化工原料:** 基礎酸鹼/溶劑供應商

**中游 (製造):**
- **國化** (清洗劑/半導體特化品/工業化學品)
- **[[和淞科技]]** (子公司，半導體濕製程化學品)

**下游 (終端):**
- **半導體:** [![台積電](https://img.shields.io/badge/%E5%8F%B0%E7%A9%8D%E9%9B%BB-blue)](2330_%E5%8F%B0%E7%A9%8D%E9%9B%BB.md)、[![Micron](https://img.shields.io/badge/Micron-blue)](MU_Micron.md) — 濕製程化學品
- **工業:** 工業清洗/表面處理客戶
