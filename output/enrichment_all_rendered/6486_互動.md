# 6486_互動

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 3,832 百萬台幣
**企業價值:** 3,561 百萬台幣

互動國際數位 (6486，IDT) 隸屬於 [![佳世達](https://img.shields.io/badge/%E4%BD%B3%E4%B8%96%E9%81%94-blue)](2352_%E4%BD%B3%E4%B8%96%E9%81%94.md) 集團，為台灣頂尖的電信、媒體及寬頻網路系統整合商。公司專注於代理歐美一線硬體與軟體品牌，為客戶提供 [![5G](https://img.shields.io/badge/5G-green)](../themes/5G.md) 骨幹網路、微波無線傳輸、數位電視多媒體播送、地理資訊系統 (GIS) 及雲端資安之完整系統建置與售後服務。主要代理品牌包括 [[Cisco]]、[[Ericsson]]、[[ESRI]] (全球 GIS 軟體龍頭) 及 [[AWS]] 等國際大廠。隨著 [![5G](https://img.shields.io/badge/5G-green)](../themes/5G.md) 企業專網、[![低軌衛星](https://img.shields.io/badge/%E4%BD%8E%E8%BB%8C%E8%A1%9B%E6%98%9F-green)](../themes/%E4%BD%8E%E8%BB%8C%E8%A1%9B%E6%98%9F.md) 通訊及智慧城市蓬勃發展，互動國際已將業務延伸至高鐵軌道通訊、智慧城市防災等大型基礎設施智慧化建置。
