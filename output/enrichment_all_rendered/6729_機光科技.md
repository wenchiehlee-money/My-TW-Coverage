# 6729 - 機光科技

## 業務簡介
**板塊:** Basic Materials
**產業:** Chemicals
**市值:** 1,135 百萬台幣
**企業價值:** 1,151 百萬台幣

機光科技 (6729，Luminescence Technology / Lumtec) 為台灣唯一完全自主研發之[[OLED]]有機發光材料製造商，產品行銷逾 70 國。核心產品涵蓋 [[OLED]] 發光/傳輸材料、[[TADF]] (熱活化延遲螢光) 材料、[[OPV]] (有機光伏) 材料、[[鈣鈦礦太陽能電池]]材料、[[聚醯亞胺]] (PI) 單體及 ITO 玻璃。毛利率約 65%。下游客戶涵蓋[[Merck]]、[[Dow]]、[[3M]]等全球 [[OLED]] 材料巨頭。PI 單體供應 [![達邁](https://img.shields.io/badge/%E9%81%94%E9%82%81-blue)](3645_%E9%81%94%E9%82%81.md)、[![台虹](https://img.shields.io/badge/%E5%8F%B0%E8%99%B9-blue)](8039_%E5%8F%B0%E8%99%B9.md) 等 PI 膜廠用於軟性電路板及手機散熱。重要股東及共同開發夥伴為 [![台化](https://img.shields.io/badge/%E5%8F%B0%E5%8C%96-blue)](1326_%E5%8F%B0%E5%8C%96.md)。
