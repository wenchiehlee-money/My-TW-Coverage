# 1321 - 大洋

## 業務簡介
**板塊:** Basic Materials
**產業:** Specialty Chemicals
**市值:** 7,095 百萬台幣
**企業價值:** 10,370 百萬台幣

大洋塑膠 (1321，Ocean Plastics) 為台灣[[PVC]]膠布/膠皮專業加工廠。上游[[PVC]]粉及可塑劑原料採購自 [![台塑](https://img.shields.io/badge/%E5%8F%B0%E5%A1%91-blue)](1301_%E5%8F%B0%E5%A1%91.md)、[[華夏海灣]]、[[聯成化科]]。產品涵蓋 PVC 膠布、膠皮及建材用 PVC 製品，應用於雨衣、帳篷、充氣產品、桌布及建材裝潢。外銷比重約四成。
