# 2030 - 彰源

## 業務簡介
**板塊:** Basic Materials
**產業:** Steel
**市值:** 4,705 百萬台幣
**企業價值:** 9,151 百萬台幣

彰源企業股份有限公司 (Froch Enterprise Co., Ltd.) 成立於 1970 年，總部位於台灣[[雲林]]斗六。公司為台灣第一大**不鏽鋼管**及**不鏽鋼板**製造廠。主要產品包括[[不鏽鋼配管]]、[[構造管]]、[[鍋爐管]]及[[不鏽鋼板捲]]。彰源產品規格齊全，廣泛應用於石化、造紙、食品、能源及[[半導體]]電子廠房建設。內外銷比重約為 3:7，外銷市場遍及全球 100 多國。

## 供應鏈位置
**上游 (原料):**
- **不鏽鋼捲/板:** 主要向 [![燁聯](https://img.shields.io/badge/%E7%87%81%E8%81%AF-blue)](9957_%E7%87%81%E8%81%AF.md) (9957)、[![唐榮](https://img.shields.io/badge/%E5%94%90%E6%A6%AE-blue)](2035_%E5%94%90%E6%A6%AE.md) (2035)、[[華新麗華]] (1605) 及國外鋼廠採購 304/316 系列不鏽鋼捲。

**下游應用:**
- **石化/能源:** 煉油廠、化工廠、發電廠之輸送管線 (大口徑管)。
- **營建/工程:** 建築結構、欄杆、扶手、以及高科技廠房 (晶圓廠) 之基礎管線。
- **機械/汽車:** 排氣管、機械結構件。
