# 2329 - 華泰

## 業務簡介
**板塊:** Technology
**產業:** Semiconductors
**市值:** 25,534 百萬台幣
**企業價值:** 25,577 百萬台幣

華泰電子 (Orient Semiconductor Electronics, OSE) 成立於 1971 年，為台灣老牌[[半導體]]封測與電子代工廠，總部位於高雄。公司業務分為兩大事業群：**半導體封測 (IC)** 與 **電子製造服務 (EMS)**。
1.  **IC 封測:** 專注於 **NAND Flash** [![DRAM/記憶體](https://img.shields.io/badge/DRAM%2F%E8%A8%98%E6%86%B6%E9%AB%94-green)](../themes/DRAM.md) 封裝測試，主要產品包括 SSD、eMMC、記憶卡等。
2.  **EMS 代工:** 提供 SMT 表面黏著技術服務，近年成功切入 **[![AI 伺服器](https://img.shields.io/badge/AI%20%E4%BC%BA%E6%9C%8D%E5%99%A8-green)](../themes/AI_%E4%BC%BA%E6%9C%8D%E5%99%A8.md)** 組裝代工，主要客戶為美超微 (Supermicro)。

## 供應鏈位置
**上游 (原料/IC):**
- **晶圓/Controller:** 向群聯 (Phison)、江波龍 (Longsys) 等模組廠或 Controller 廠接收晶圓或顆粒進行封測。
- **PCB/被動元件:** 用於 [[EMS]] 組裝。

**下游應用:**
- **儲存:** [[消費性電子]]、工控、車用之 SSD、記憶卡。
- **伺服器:** [[AI]] [[伺服器]]主機板組裝 (Server PCBA)。

## 主要客戶及供應商
### 主要客戶
- **IC 封測:** 金士頓 (Kingston) - 既是客戶也是大股東, 群聯 (Phison), 江波龍 (Longsys)。
- **EMS:** 美超微 (Supermicro) - 佔 [[EMS]] 營收比重極高，供應 [[AI]] Server 主機板。

### 主要供應商
- **原料:** [[導線架]]、基板供應商。
