# 2014 - 中鴻

## 業務簡介
**板塊:** Basic Materials
**產業:** Steel
**市值:** 24,117 百萬台幣
**企業價值:** 34,637 百萬台幣

中鴻鋼鐵股份有限公司 (Chung Hung Steel Corporation) 成立於 1983 年，前身為燁隆企業，現為[[中鋼集團]]旗下主要成員。公司總部位於台灣[[高雄]]，主要從事熱軋鋼捲、冷軋鋼捲、鍍鋅鋼捲及鋼管 (API 石油管、結構管) 之生產與銷售。中鴻定位為 [![中鋼](https://img.shields.io/badge/%E4%B8%AD%E9%8B%BC-blue)](2002_%E4%B8%AD%E9%8B%BC.md) 集團之下游加工與單軋廠，產品廣泛應用於五金、建材、汽車、家電及能源產業，為台灣重要之單軋廠及鋼管製造商。

## 供應鏈位置
**上游 (原料):**
- **扁鋼胚 (Slab):** 主要向母公司 [![中鋼](https://img.shields.io/badge/%E4%B8%AD%E9%8B%BC-blue)](2002_%E4%B8%AD%E9%8B%BC.md) (CSC) 及[[日本製鐵]] (Nippon Steel) 採購，部分來自[[中龍鋼鐵]]。
- **熱軋鋼捲:** 部分作為冷軋及製管原料。

**下游應用:**
- **鋼管/五金:** 石油天然氣輸送管 (API 管)、結構用管、傢俱五金。
- **建材:** 鍍鋅鋼捲用於屋頂、烤漆板底材。
- **汽車/家電:** 冷軋鋼板用於車體鈑金、家電外殼。

## 主要客戶及供應商
### 主要客戶
- **鋼管業:** 國內外製管廠。
- **加工業:** 裁剪中心、鍍鋅廠 ([![燁輝](https://img.shields.io/badge/%E7%87%81%E8%BC%9D-blue)](2023_%E7%87%81%E8%BC%9D.md)、[![盛餘](https://img.shields.io/badge/%E7%9B%9B%E9%A4%98-blue)](2029_%E7%9B%9B%E9%A4%98.md))。
- **能源業:** 北美油氣開採商 (API 鋼管)。
