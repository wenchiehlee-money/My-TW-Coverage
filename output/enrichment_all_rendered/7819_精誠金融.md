# 7819 - 精誠金融

## 業務簡介
**板塊:** Technology
**產業:** Software - Infrastructure
**市值:** 887 百萬台幣
**企業價值:** 729 百萬台幣

精誠金融科技股份有限公司 (7819) 為台灣線下實體店面刷卡終端設備市場之絕對領導者，由台灣軟體業龍頭[[精誠資訊]] (6214) 分拆上市。公司掌握全台逾七成刷卡終端設備銷售市佔率，以及超過半數之維修保養業務。服務涵蓋多品牌刷卡機代理銷售、全台刷卡機維運與特店商化服務、信用卡收單系統建置、電子發票與第三方支付加值服務。主要客戶為各大信用卡收單銀行與大型連鎖零售集團。2022 年獲 [![綠界科技](https://img.shields.io/badge/%E7%B6%A0%E7%95%8C%E7%A7%91%E6%8A%80-blue)](6763_%E7%B6%A0%E7%95%8C%E7%A7%91%E6%8A%80.md) 策略入股後，積極跨入數位支付市場，推展點數支付、電子發票與第三方行動支付方案。

## 供應鏈位置
**上游 (刷卡機原廠):**
- **刷卡終端:** [[VeriFone]]、PAX (百富)、[![虹堡](https://img.shields.io/badge/%E8%99%B9%E5%A0%A1-blue)](5258_%E8%99%B9%E5%A0%A1.md) (Castles) — 刷卡機硬體原廠
- **加密模組:** 金流後台加密運算模組供應商
- **母公司:** [[精誠資訊]] (6214) — 企業後台系統支援

**中游 (金流設備服務):**
- **精誠金融科技** (刷卡終端設備代理銷售、維運商化服務、收單系統建置、電子發票與第三方支付)

**下游 (銀行與零售):**
- **收單銀行:** [[聯邦銀行]]、[[新光銀行]]等 — 刷卡機佈建
- **零售集團:** [[萊爾富]]等大型連鎖通路
- **策略夥伴:** [![綠界科技](https://img.shields.io/badge/%E7%B6%A0%E7%95%8C%E7%A7%91%E6%8A%80-blue)](6763_%E7%B6%A0%E7%95%8C%E7%A7%91%E6%8A%80.md) — 數位支付合作
