# 5386 - 青雲

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 11,582 百萬台幣
**企業價值:** 14,265 百萬台幣

青雲 (Albatron) 為專業 **資訊通路代理商**，從早期的板卡製造轉型為代理通路。
主要代理產品：
1.  **記憶體**: **[[Micron]] (美光)** 全系列產品 ([[DRAM]]/SSD)，主要應用於[[伺服器]]。
2.  **板卡/伺服器**: **技嘉 (Gigabyte)** 顯示卡、主機板、[[伺服器]] (Giga Computing)。
3.  **其他**: PNY 顯卡、Apacer 產品。
受惠於 [[AI]] [[伺服器]]需求，[![HBM](https://img.shields.io/badge/HBM-green)](../themes/HBM.md) 與高階 Server [[DRAM]] 需求強勁。

    *   **記憶體**: **[[Micron]]**.
    *   **板卡/系統**: **技嘉 (Gigabyte)**, **Supermicro**.
*   **下游**:
    *   **企業**: 系統整合商 (SI), [![資料中心](https://img.shields.io/badge/%E8%B3%87%E6%96%99%E4%B8%AD%E5%BF%83-green)](../themes/%E8%B3%87%E6%96%99%E4%B8%AD%E5%BF%83.md) 建置.
