# 1303 - 南亞

## 業務簡介
**板塊:** Basic Materials
**產業:** Specialty Chemicals
**市值:** 1,122,211 百萬台幣
**企業價值:** 1,243,271 百萬台幣

南亞塑膠 (1303，Nan Ya Plastics) 為[[台塑集團]]四大公司之一，台灣最大塑膠加工及電子材料製造商，營收約 2,600 億元。四大事業群：(1) 塑膠加工 — [[PVC]]管材/膠布、[[BOPP]]薄膜、工程塑膠；(2) 化工 — [[環氧樹脂]]、[[雙酚A]]、可塑劑、[[乙二醇]]；(3) 電子材料 — [[銅箔基板]] (CCL，全球前三大)、[[玻纖布]] (全球前三大)、[[銅箔]]，供應 [![欣興](https://img.shields.io/badge/%E6%AC%A3%E8%88%88-blue)](3037_%E6%AC%A3%E8%88%88.md)、[![臻鼎](https://img.shields.io/badge/%E8%87%BB%E9%BC%8E-blue)](4958_%E8%87%BB%E9%BC%8E-KY.md)、[![華通](https://img.shields.io/badge/%E8%8F%AF%E9%80%9A-blue)](2313_%E8%8F%AF%E9%80%9A.md)、[![聯茂](https://img.shields.io/badge/%E8%81%AF%E8%8C%82-blue)](6213_%E8%81%AF%E8%8C%82.md)、[![台光電](https://img.shields.io/badge/%E5%8F%B0%E5%85%89%E9%9B%BB-blue)](2383_%E5%8F%B0%E5%85%89%E9%9B%BB.md) 等 PCB 大廠，受惠 [![AI 伺服器](https://img.shields.io/badge/AI%20%E4%BC%BA%E6%9C%8D%E5%99%A8-green)](../themes/AI_%E4%BC%BA%E6%9C%8D%E5%99%A8.md) 需求；(4) 聚酯纖維 — [[PET]]膜/加工絲。重要轉投資涵蓋子公司[[南亞電路板]] (南電，8046，全球前三大 [![ABF 載板](https://img.shields.io/badge/ABF%20%E8%BC%89%E6%9D%BF-green)](../themes/ABF_%E8%BC%89%E6%9D%BF.md) 供應商，服務 [![Intel](https://img.shields.io/badge/Intel-blue)](INTC_Intel.md)、[![AMD](https://img.shields.io/badge/AMD-blue)](AMD_AMD.md)、[![NVIDIA](https://img.shields.io/badge/NVIDIA-blue)](NVDA_NVIDIA.md)) 及[[南亞科技]] (2408，DRAM)。上游石化原料來自集團內 [![台塑](https://img.shields.io/badge/%E5%8F%B0%E5%A1%91-blue)](1301_%E5%8F%B0%E5%A1%91.md)、[![台化](https://img.shields.io/badge/%E5%8F%B0%E5%8C%96-blue)](1326_%E5%8F%B0%E5%8C%96.md)、[[台塑石化]]。
