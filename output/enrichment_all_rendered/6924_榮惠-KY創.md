# 6924_榮惠-KY創

## 業務簡介
**板塊:** Technology
**產業:** Electronic Components
**市值:** 2,058 百萬台幣
**企業價值:** 1,661 百萬台幣

榮惠-KY (6924，EIKEI) 為輕資產模式的利基型 PCB 與電子零組件整合服務商。公司不自設 PCB 工廠，而是以設計、品管與供應鏈管理為核心能力，承接日系車廠及國際品牌客戶高度客製化的 PCB 訂單。

業務結構與動能：(1) 車用 PCB — 成功打入日本車用電子供應鏈，透過模組拼板設計與日本車規級品管，委託合作板廠代工生產；(2) 電子零組件整合 — 提供跨國供應鏈調度、物流倉儲與零組件整合服務；(3) 東南亞擴張 — 隨日系客戶南進泰國、印尼，拓展東南亞市場。上游合作數十家 PCB 製造板廠，下游客戶以日本車用電子 Tier 1/Tier 2 為主。

## 供應鏈位置
**上游 (PCB 製造):**
- **基板材料:** [[銅箔]]基板 (CCL) 供應商
- **PCB 代工:** 數十家台灣如 [![欣興](https://img.shields.io/badge/%E6%AC%A3%E8%88%88-blue)](3037_%E6%AC%A3%E8%88%88.md)、中國及東南亞合作 PCB 板廠

**中游 (整合服務):**
- **PCB 設計:** **榮惠** (利基型 PCB 模組拼板設計)
- **品管:** **榮惠** (日本車規級品質管理)
- **供應鏈:** **榮惠** (跨國供應鏈調度與物流倉儲)

**下游 (車用電子):**
- **車用 Tier 1:** 日本車用電子系統廠如 [[Denso]]、[[Aisin]] — 車規 PCB
- **消費電子:** 消費電子品牌 — 利基型 PCB
- **工控設備:** 工業控制設備商 — 客製化 PCB
- **AI 散熱:** [![AI 伺服器](https://img.shields.io/badge/AI%20%E4%BC%BA%E6%9C%8D%E5%99%A8-green)](../themes/AI_%E4%BC%BA%E6%9C%8D%E5%99%A8.md) 水冷散熱模組廠 — PCB
