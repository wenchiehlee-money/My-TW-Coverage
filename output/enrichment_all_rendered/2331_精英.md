# 2331 - 精英

## 業務簡介
**板塊:** Technology
**產業:** Computer Hardware
**市值:** 9,922 百萬台幣
**企業價值:** 2,719 百萬台幣

精英電腦 (2331，Elitegroup Computer Systems，ECS) 成立於 1987 年，總部位於台北，為全球知名主機板及迷你電腦設計製造商。公司產品涵蓋桌上型電腦主機板 ([![Intel](https://img.shields.io/badge/Intel-blue)](INTC_Intel.md) 及 [![AMD](https://img.shields.io/badge/AMD-blue)](AMD_AMD.md) 平台)、迷你電腦 (LIVA 品牌)、筆記型電腦、Chromebook、顯示卡及工業電腦主機板。

近年積極布局 [[AI]] PC 及輕電競主機板市場，並跨足數位看板、智慧零售及商務應用解決方案。在工業應用領域，開發 [[IPC]] 工業電腦主機板及立方衛星 (CubeSat) 模組。集團設有全球業務據點，產品銷售遍及亞洲、美洲及歐洲市場。
