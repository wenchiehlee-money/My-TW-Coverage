# 3105 - 穩懋

## 業務簡介
**板塊:** Technology
**產業:** Semiconductors
**市值:** 23,520 百萬台幣
**企業價值:** 129,901 百萬台幣

穩懋[[半導體]] (Win Semiconductors) 是 **全球最大** 的化合物[[半導體]]晶圓代工廠 (Pure-play Foundry)，市佔率超過 70%。
公司專注於 **砷化鎵 (GaAs)** 與 **[![氮化鎵](https://img.shields.io/badge/%E6%B0%AE%E5%8C%96%E9%8E%B5-green)](../themes/%E6%B0%AE%E5%8C%96%E9%8E%B5.md) (GaN)** 製程技術，是無線通訊領域的關鍵供應商。
核心產品與技術優勢：
1.  **功率放大器 (PA)**: 為 [![5G](https://img.shields.io/badge/5G-green)](../themes/5G.md) 手機、Wi-Fi 6E/7 路由器不可或缺的關鍵元件。
2.  **光電元件 (Optoelectronics)**: 生產 **3D 感測 ([![VCSEL](https://img.shields.io/badge/VCSEL-green)](../themes/VCSEL.md))** 與 **LiDAR** 雷射晶片，廣泛應用於 FaceID 與智慧駕駛。
3.  **先進製程技術**: 具備 HBT, pHEMT, BiHEMT, GaN-on-SiC 等多樣化製程，滿足高頻、高功率需求。
4.  **AI 與衛星佈局**: 積極切入 **AI [![資料中心](https://img.shields.io/badge/%E8%B3%87%E6%96%99%E4%B8%AD%E5%BF%83-green)](../themes/%E8%B3%87%E6%96%99%E4%B8%AD%E5%BF%83.md)** ([[光通訊]]) 與 **[![低軌衛星](https://img.shields.io/badge/%E4%BD%8E%E8%BB%8C%E8%A1%9B%E6%98%9F-green)](../themes/%E4%BD%8E%E8%BB%8C%E8%A1%9B%E6%98%9F.md)** 供應鏈，與 [![Broadcom](https://img.shields.io/badge/Broadcom-blue)](AVGO_Broadcom.md) 等大廠合作緊密。
