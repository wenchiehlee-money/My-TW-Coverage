# 8410 - 森田

## 業務簡介
**板塊:** Basic Materials
**產業:** Specialty Chemicals
**市值:** 1,123 百萬台幣
**企業價值:** 433 百萬台幣

森田印刷 (8410，Sentien Printing) 為國際級先進科技印刷廠，專精熱轉印膜 (HTF)、模內貼標 ([[IML]])、模內印刷 ([[IMR]])、模內裝飾 ([[IMD]]) 及嵌入件射出成型 (Insert Molding) 技術。通過 ISO9001 及[[RBA]]認證。NB-[[IMR]]產品穩定供應國際筆電大廠如 [![HP Inc.](https://img.shields.io/badge/HP%20Inc.-blue)](HPQ_HP%20Inc..md)、[![Dell](https://img.shields.io/badge/Dell-blue)](DELL_Dell.md)、[[Lenovo]]、[![華碩](https://img.shields.io/badge/%E8%8F%AF%E7%A2%A9-blue)](2357_%E8%8F%AF%E7%A2%A9.md)、[![宏碁](https://img.shields.io/badge/%E5%AE%8F%E7%A2%81-blue)](2353_%E5%AE%8F%E7%A2%81.md)。同時拓展汽車內飾件裝飾膜、金屬/玻璃低溫轉印等新應用。

## 供應鏈位置
**上游 (原料):**
- **基膜:** PET/PMMA 膜供應商
- **油墨/塗料:** 特殊油墨及離型劑

**中游 (製造):**
- **森田** (熱轉印/[[IML]]/[[IMR]]/[[IMD]] 先進印刷)

**下游 (終端):**
- **筆電 (NB-IMR):** [![HP Inc.](https://img.shields.io/badge/HP%20Inc.-blue)](HPQ_HP%20Inc..md)、[![Dell](https://img.shields.io/badge/Dell-blue)](DELL_Dell.md)、[[Lenovo]]、[![華碩](https://img.shields.io/badge/%E8%8F%AF%E7%A2%A9-blue)](2357_%E8%8F%AF%E7%A2%A9.md)、[![宏碁](https://img.shields.io/badge/%E5%AE%8F%E7%A2%81-blue)](2353_%E5%AE%8F%E7%A2%81.md) — 筆電機殼裝飾膜
- **汽車:** 汽車內飾件裝飾膜
- **消費品:** 家電/消費品表面裝飾
