# 6231_系微

## 業務簡介
**板塊:** Technology
**產業:** Software - Application
**市值:** 9,199 百萬台幣
**企業價值:** 8,246 百萬台幣

系微股份有限公司 (6231，Insyde Software) 是一家全球領先的系統韌體(Firmware)與軟體工程服務供應商。公司的核心產品為UEFI系統韌體(如InsydeH2O BIOS)以及基板管理控制器(BMC)韌體(如Supervyse)。系微的韌體是銜接電腦硬體與作業系統的關鍵橋樑，廣泛應用於個人電腦、[[伺服器]]、[[物聯網]]及邊緣運算設備。近年來，受惠於[[AI]] PC浪潮(如 [![Intel](https://img.shields.io/badge/Intel-blue)](INTC_Intel.md)/[![AMD](https://img.shields.io/badge/AMD-blue)](AMD_AMD.md) 新晶片及高通Snapdragon X平台)與[[AI[[伺服器]]]]的強勁需求，系微的BIOS授權金及NRE(委託設計)收入穩健增長，在[[AI]] PC市場擁有極高市佔率。

## 供應鏈位置
*   **上游**: [![Intel](https://img.shields.io/badge/Intel-blue)](INTC_Intel.md)、[![AMD](https://img.shields.io/badge/AMD-blue)](AMD_AMD.md)、[![NVIDIA](https://img.shields.io/badge/NVIDIA-blue)](NVDA_NVIDIA.md)、高通([![Qualcomm](https://img.shields.io/badge/Qualcomm-blue)](QCOM_Qualcomm.md))、[[Arm]]及Aspeed(信驊)等全球頂尖晶片設計原廠。
*   **中游**: **系微** (UEFI BIOS系統韌體、BMC[[伺服器]]管理韌體之設計開發、客製化修改及授權服務)。
*   **下游**: 全球各大電腦及[[伺服器]]品牌廠([[OEM]])、專業電子代工廠([[ODM]])及雲端 [![資料中心](https://img.shields.io/badge/%E8%B3%87%E6%96%99%E4%B8%AD%E5%BF%83-green)](../themes/%E8%B3%87%E6%96%99%E4%B8%AD%E5%BF%83.md) 業者。
