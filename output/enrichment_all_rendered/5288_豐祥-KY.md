# 5288 - 豐祥-KY

## 業務簡介
**板塊:** Industrials
**產業:** Conglomerates
**市值:** 12,755 百萬台幣
**企業價值:** 10,862 百萬台幣

豐祥控股（Eurocharm Holdings，KY公司）成立於1974年，在開曼群島註冊，主要生產據點位於台灣及越南。公司為專業金屬零組件製造商，核心能力涵蓋[[沖壓]]、[[焊接]]、[[電鍍]]、塗裝等金屬加工之垂直整合製程，並取得 ISO 9001、[[IATF 16949]]（汽車產業品質管理）及 [[ISO 13485]]（醫療器材品質管理）等國際認證。四大業務領域：（1）**機車零組件**（最大營收來源），為越南主要機車機構件供應商之一；（2）**休閒車輛零組件**（重型機車、沙灘車、雪車）；（3）**醫療器材**（病床、輪椅結構件）；（4）**汽車零部件**。越南廠員工約3,500人，具備成本及在地化供應鏈優勢，近年積極切入 [![電動車](https://img.shields.io/badge/%E9%9B%BB%E5%8B%95%E8%BB%8A-green)](../themes/%E9%9B%BB%E5%8B%95%E8%BB%8A.md)（如[[VinFast]]）及 [![AI 伺服器](https://img.shields.io/badge/AI%20%E4%BC%BA%E6%9C%8D%E5%99%A8-green)](../themes/AI_%E4%BC%BA%E6%9C%8D%E5%99%A8.md) 機殼等新興應用領域。

## 供應鏈位置
**上游 (金屬原料):**
- **鋼鐵:** 越南及國際鋼鐵供應商
- **鋁材:** 鋁合金板材與型材供應商
- **表面處理材料:** 電鍍液、塗料等化學品

**中游 (金屬加工製造):**
- **豐祥-KY** — [[沖壓]]、[[焊接]]、[[電鍍]]、塗裝之垂直整合金屬零組件製造

**下游 (品牌終端):**
- **機車:** [[Honda]]（本田，最大客戶）、[[Yamaha]]、[[Ducati]]

- **醫療器材:** [[Stryker]]（史賽克）、[[Hill-Rom]]
- **汽車:** [[Toyota]]、[[Ford]]
- **電動車:** [[VinFast]]（越南電動車）
