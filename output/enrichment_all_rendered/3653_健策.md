# 3653 - 健策

## 業務簡介
**板塊:** Technology
**產業:** Electronic Components
**市值:** 485,686 百萬台幣
**企業價值:** 475,574 百萬台幣

健策精密 (Kenmec) 為台灣最大的 **均熱片 (Vapor Chamber)** 供應商，也是全球精密沖壓及[[散熱]]解決方案的領導者。
公司產品廣泛應用於[[伺服器]]、[[AI]] 運算、車用電子及通訊領域。
核心優勢與亮點：
1.  **[![AI 伺服器](https://img.shields.io/badge/AI%20%E4%BC%BA%E6%9C%8D%E5%99%A8-green)](../themes/AI_%E4%BC%BA%E6%9C%8D%E5%99%A8.md) 供應鏈**: 為 [![AMD](https://img.shields.io/badge/AMD-blue)](AMD_AMD.md)、[![Intel](https://img.shields.io/badge/Intel-blue)](INTC_Intel.md) 及 [![NVIDIA](https://img.shields.io/badge/NVIDIA-blue)](NVDA_NVIDIA.md) 的關鍵供應商，供應其 GPU 與 CPU 所需的高階均熱片與[[散熱]]模組。
2.  **散熱技術領先**: 具備冷鍛均熱片、真空腔[[散熱]]技術，並積極佈局 [[AI]] [[伺服器]]所需的 **液冷** [[散熱]]模組與微通道蓋板 (MCL)。
3.  **伺服器扣件 (ILM)**: 具備[[伺服器]]處理器[[連接器]]緊固件 (ILM) 的設計與製造能力，在[[伺服器]]市場具備極高市佔。
4.  **自動化能量**: 具備自有[[自動化]]設備開發團隊，支援生產線高度[[自動化]]，提升產品良率與交期競爭力。
