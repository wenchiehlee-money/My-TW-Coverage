# 6516_勤崴國際

## 業務簡介
**板塊:** Technology
**產業:** Scientific & Technical Instruments
**市值:** 3,105 百萬台幣
**企業價值:** 2,348 百萬台幣

勤崴國際科技股份有限公司 (6516，KingwayTek) 隸屬於 [![中華電信](https://img.shields.io/badge/%E4%B8%AD%E8%8F%AF%E9%9B%BB%E4%BF%A1-blue)](2412_%E4%B8%AD%E8%8F%AF%E9%9B%BB.md) 集團，是台灣最具代表性的電子地圖、導航系統及[[車聯網]]平台開發商。勤崴憑藉在台灣電子地圖市場超過七成的絕對市佔率(為 [![Google](https://img.shields.io/badge/Google-blue)](GOOGL_Google.md) Maps在台灣的圖資合作夥伴)，已成功轉型為智慧移動系統整合商。其業務涵蓋商用車隊管理平台、[[ADAS]](先進駕駛輔助系統)高精地圖，以及Level 4全自動駕駛巴士的自駕營運服務。公司不僅切入歐系車廠及Toyota的[[車聯網]]系統，更成功在 [![台積電](https://img.shields.io/badge/%E5%8F%B0%E7%A9%8D%E9%9B%BB-blue)](2330_%E5%8F%B0%E7%A9%8D%E9%9B%BB.md) 廠區落地自駕接駁專案。

## 供應鏈位置
*   **上游**: 衛星影像資料、航空/地理測繪數據服務、雲端運算基礎設施(IaaS)及車載硬體(OBU)製造商。
*   **中游**: **勤崴國際** (電子圖資繪製/銷售、[[車聯網]]/車隊管理雲端平台及自動駕駛系統整合服務)。
*   **下游**: 大型網路搜尋業主([![Google](https://img.shields.io/badge/Google-blue)](GOOGL_Google.md)/Yahoo)、國內外各大車輛品牌([[OEM]])、大型企業物流車隊及政府單位。

- [![Google](https://img.shields.io/badge/Google-blue)](GOOGL_Google.md)(圖資主力客戶)、和泰汽車(Toyota聯網服務)、[[BMW]]、[![台積電](https://img.shields.io/badge/%E5%8F%B0%E7%A9%8D%E9%9B%BB-blue)](2330_%E5%8F%B0%E7%A9%8D%E9%9B%BB.md)(廠區自駕接駁)及中興保全。
