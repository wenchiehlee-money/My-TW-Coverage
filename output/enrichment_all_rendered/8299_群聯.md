# 8299 - 群聯

## 業務簡介
**板塊:** Technology
**產業:** Semiconductors
**市值:** 334,945 百萬台幣
**企業價值:** 334,586 百萬台幣

群 [![聯電](https://img.shields.io/badge/%E8%81%AF%E9%9B%BB-blue)](2303_%E8%81%AF%E9%9B%BB.md) 子 (8299，Phison) 為全球 [![NAND Flash](https://img.shields.io/badge/NAND%20Flash-blue)](../themes/NAND_Flash.md) 儲存控制晶片及解決方案領導廠商，每年全球銷售超過 6 億顆控制晶片。產品涵蓋 [[SSD]] 控制晶片 ([[PCIe]]/SATA)、[[eMMC]]、[[UFS]]、SD 及 USB 介面控制器，從 IP 授權到晶片設計至系統整合之完整方案，服務消費、工業及企業級市場。

## 供應鏈位置
**上游 (NAND 原廠):**
- **NAND Flash:** [[Kioxia]] (合作夥伴)、[![Micron](https://img.shields.io/badge/Micron-blue)](MU_Micron.md)

**中游 (控制晶片設計):**
- **NAND 控制器:** **群聯** (全球 NAND Flash 控制晶片龍頭，年銷 6 億+顆)

**下游 (儲存品牌):**
- **主要平台:** AI Ecosystem Module (~38%), Embedded ODM Module (~25%), Industrial Module (~15%), Controller (~10%), Retail Module (~8%), Others (~4%).
- **記憶體品牌:** [[Kingston]] (最大客戶)
- **OEM/ODM:** 全球品牌及 OEM/ODM
