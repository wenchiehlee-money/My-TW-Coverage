# 3229 - 晟鈦

## 業務簡介
**板塊:** Technology
**產業:** Electronic Components
**市值:** 2,458 百萬台幣
**企業價值:** 2,502 百萬台幣

晟鈦科技 ([[Cheer Time]]) 主要從事 [[PCB]] 製造與加工，以小量多樣與急件服務為經營特色，避開大量生產紅海競爭。

核心業務：(1) [[PCB]] 鑽孔代工 — 為同業提供鑽孔加工服務，日產能約 8,000 片面板；(2) 多層 [[PCB]] 製造 — 生產 HDI、Load Board (IC 測試板)、晶圓測試板、老化板、軟硬結合板等高階產品；(3) 磷銅球製造 — 自 2014 年成立磷銅球事業部，採上拉法連鑄技術生產 25mm/50mm/55mm 磷銅球，年產約 3,600-3,800 噸，供應 [[PCB]] 電鍍製程。近期透過轉投資切入 [![AI 伺服器](https://img.shields.io/badge/AI%20%E4%BC%BA%E6%9C%8D%E5%99%A8-green)](../themes/AI_%E4%BC%BA%E6%9C%8D%E5%99%A8.md) 與網通應用高階 [[PCB]] 市場。
