# 3645 - 達邁

## 業務簡介
**板塊:** Technology
**產業:** Electronic Components
**市值:** 8,438 百萬台幣
**企業價值:** 9,073 百萬台幣

達邁科技 (Taimide) 為台灣最大的 **聚醯亞胺薄膜 (PI Film)** 專業製造商，全球市佔位居前四名。
PI 薄膜因具備極佳的耐高溫、電絕緣與輕薄特性，在電子產業中被譽為「黃金薄膜」。
公司發展重點：
1.  **PI 薄膜專家**: 產品涵蓋黑色 PI (營收主力)、透明 PI、高頻高速用 PI 及石墨[[散熱]] PI。
2.  **[![Meta](https://img.shields.io/badge/Meta-blue)](META_Meta.md) 供應鏈**: 透明 PI 已成功打入 [![Meta](https://img.shields.io/badge/Meta-blue)](META_Meta.md) 的 **AR 眼鏡** 供應鏈，負責眼球追蹤與操控線路基材。
3.  **先進封裝**: 產品已導入 IC 封裝與先進封裝流程，供應 COF (覆晶薄膜) 相關應用。
4.  **折疊裝置**: 開發高強度且透明的 PI 材料，應用於折疊手機與可穿戴設備。
